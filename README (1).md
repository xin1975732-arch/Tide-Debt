# 围涂 · 交互式阅读器

《围涂》是“账本三部曲”的第三部。本项目将原阅读网页的首页、二十章正文、样式和交互脚本整理为一个独立的 `index.html`，可直接放入 GitHub 仓库，也可以下载后在本地阅读。

上林县，二塘边上的老厂。欠了四十八户工友十五年的老板回来还钱，当天夜里死在档案室。

## 项目文件

- `index.html`：完整阅读器，内嵌所有正文、CSS、JavaScript、SVG 和 Canvas 绘图逻辑。
- `README.md`：项目说明。
- `.gitignore`：忽略系统文件、编辑器缓存和临时文件。

无构建步骤，无 npm 依赖，无后端服务，不加载 CDN、在线字体、图片或音频文件。风声与打桩声由浏览器 Web Audio API 实时合成。首页保留了另两部作品的链接，只有主动打开这些链接时才需要网络。

## 功能列表

- 完整书封、首页目录和二十章正文。
- 侧边目录：任意章节跳转、当前章节标识、已读提示、遮罩关闭与 Esc 关闭。
- 翻页：底部“上一页／下一页”按屏滚动，保留少量重叠内容；到章节边界后进入相邻章节。
- 翻章：保留章末上一章／下一章链接，支持键盘左右方向键。
- 支持 PageUp、PageDown 按屏翻页；目录打开时支持 Tab 焦点循环。
- 字号缩放：16、17、18、19、20、22、24 像素七档。
- 三种阅读底色：夜涂、卷宗、档案袋；首次打开时跟随系统明暗偏好。
- 阅读进度条、围塘进度标识、已读状态、首页“接着读”和段落位置恢复。
- 书封 SVG、章首 Canvas 动画、动画开关，以及正文中的锁屏、划痕和结尾效果。
- “听风”按钮：合成风声、海声与远处打桩声；声音需要用户交互后才能开始。
- 手机与桌面响应式布局，保留安全区域适配和减少动态效果偏好支持。
- 阅读设置和进度保存在当前浏览器的 localStorage 中。

## 本地启动方式

### 方法一：直接打开

将三个文件放在同一文件夹，双击 `index.html`，使用现代浏览器打开即可。网页不需要其他资源文件。

`file://` 页面上的 localStorage 行为取决于浏览器。若阅读设置不能保存，建议使用下面的本地服务方式。禁用存储不会阻止阅读，但无法跨次保留进度。

### 方法二：运行本地静态服务

安装 Python 3 后，在项目目录打开终端并执行：

    python -m http.server 8000 --bind 127.0.0.1

若系统使用 `python3` 命令，可执行：

    python3 -m http.server 8000 --bind 127.0.0.1

在浏览器访问：

    http://127.0.0.1:8000/

停止服务：在终端按 Ctrl+C。

## 上传 GitHub

将 `index.html`、`README.md` 和 `.gitignore` 上传到仓库根目录即可。项目不需要安装依赖或编译。启用静态网页托管后，以仓库根目录的 `index.html` 作为入口。

本交付仅准备源码文件，没有创建仓库或发布网站。

## 单文件结构与维护

`index.html` 按顺序包含：

1. 首屏设置恢复脚本。
2. 原阅读器公共 CSS，以及侧边目录、按屏翻页的补充 CSS。
3. `page-cover` 首页模板和 `page-ch01` 至 `page-ch20` 完整章节模板。
4. `reader-root` 当前页面挂载区。
5. 单文件路由、原阅读器交互逻辑和侧边目录／翻页增强逻辑。

所有章节正文都以可读 HTML 原文保存在模板中，没有编码压缩，也不通过网络获取。编辑正文时，修改对应 `<template>` 中的内容即可。

章节链接使用 URL 片段，示例：

- `index.html#cover`：书封。
- `index.html#cover/mulu`：首页目录。
- `index.html#ch01`：第一章。
- `index.html#ch20`：第二十章“余账”。
- `index.html#ch01/resume`：恢复第一章的已保存位置。

切换章节会重新初始化当前 HTML 文件，延续原多页阅读器的脚本、动画和音频生命周期。所有章节均已内嵌，不会请求 `ch01.html`、`reader.css` 或 `reader.js`。

为满足无外部资源依赖的要求，已移除原 Google Fonts 引用。网页使用本机宋体、楷体及系统字体回退，因此不同设备的字形可能与在线字体版本略有差异。

本地状态键以 `wt.` 开头，包括 `wt.fs`、`wt.tone`、`wt.anim`、`wt.sound`、`wt.last`、`wt.done`、`wt.pos.章号` 和 `wt.blk.章号`。不同浏览器、设备及网站来源之间不会自动同步。清除网站数据会重置阅读记录。
