# 围涂

账本三部曲第三部。中篇小说,二十章。上林县,二塘边上的老厂。

纯静态网页,没有构建步骤,没有后端。正文放在 `chapters/` 里,网页打开时现场读取、排版,所以**可以直接在 GitHub 上改字**。

## 改正文

正文在 `chapters/` 文件夹,一章一个文件:`ch01.md` 是第一章,`ch20.md` 是第二十章。

在 GitHub 上点开那一章 → 右上角铅笔图标(Edit)→ 直接改字 → 页面底部 **Commit changes**。一两分钟后网页自动更新(读者那边强制刷新一下)。

写法规则(照原样保持):

- 第一行 `## 第一章　章名`,改这里就是改章名。章名和“第一章”之间是一个全角空格。
- 一行一段,段与段之间空一行。
- 单独一行 `---` 是分节的三个小圆点。

**群聊、手机、账页、手写这类特殊排版,是按“整段原文”对应的。**
这些段落(比如群里的一句话、账页上的一行)改了字,要把 `data/book.json` 里 `rules` 中同样的那句话也改成一样,否则它会退回成普通段落(不会白屏,只是少了那张卡片的样子)。普通叙述段落随便改。

## 上线

1. 新建仓库,把本目录里的**全部文件**(含 `.nojekyll`)放在仓库根目录。
2. 仓库 Settings → Pages → Source 选 `Deploy from a branch`,Branch 选 `main`,目录选 `/ (root)`。
3. 等一两分钟,打开 `https://<用户名>.github.io/<仓库名>/`。

用网页上传时文件夹被拆平了也没关系:加载器找不到 `chapters/`、`data/` 里的文件,会到根目录找同名文件。

本地预览:在本目录运行 `python3 -m http.server 8000`,打开 `http://localhost:8000/`。直接双击 index.html 读不到正文,需要放到网站上。

## data/ 里的文件(也能在 GitHub 上直接改)

| 文件 | 管什么 |
| --- | --- |
| `data/book.json` | 书名、简介、题记、页脚、三部曲链接、每章的日期和情绪(`chapters`)、群名(`group`),以及特殊排版规则(`rules`:special 整段对应、prefix 开头对应、inline 行内红笔/铅笔/手写、fx 小动静、after 段后插卡) |
| `data/characters.json` | 人物卡:简介、身份、出场事件、关系;`mark` 是正文里自动标出的称呼 |
| `data/timeline.json` | 时间线:日期(d)、标题(t)、说明(s)、所在章(ch)、人物(who) |
| `data/recaps.json` | 每章开头的前情提要:`"5": "……"` |
| `data/cover.svg` | 书封插画 |

只改引号里的中文,引号、逗号、括号保持原样。某个 data 文件格式写错了,网页会改用 `index.html` 里原来的那份,不会白屏。

## 其他文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 入口,内含人物、时间线等的备份 |
| `loader.js` | 读取 chapters/ 和 data/,排好版交给阅读器 |
| `reader.js` / `reader.css` | 阅读器内核(路由、排版、字号、底色、进度) |
| `features.js` / `features.css` | 人物检索与关系图、时间线、全文搜索、划线批注书签金句卡、我的书房、分享 |
| `theme.css` / `cards.css` | 围涂自己的外观与卡片(手机、群聊、账页等) |
| `scene.js` / `wt.js` | 海涂画面、风声、章首案卷号、书封、目录“核”字、围垦进度 |
| `ch01.html` … `ch20.html` | 旧版每章单页的地址,打开后跳到 `index.html#chNN` |
| `.nojekyll` | 告诉 GitHub Pages 不要用 Jekyll 处理 |

## 功能

阅读(三种底色、字号、风声、续读、前情提要)、人物检索与关系图、时间线、全文搜索、划线批注书签金句卡、我的书房、三部曲跳转、分享某章某段的链接。划线、批注、书签、进度存在读者自己的浏览器里。没有评论和读后感(需要后端)。

关系图从 jsDelivr 加载 vis-network,字体用 Google Fonts;加载不了时分别退回人名列表和系统字体。
