# 围涂

账本三部曲第三部。中篇小说,二十章。上林县,二塘边上的老厂。

这是《围涂》的网页阅读器,纯静态,没有构建步骤,不依赖 npm,也没有后端。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 入口。正文、人物、时间线、回顾都以 JSON 内嵌在这一页里 |
| `reader.js` / `reader.css` | 阅读器内核(路由、排版、字号、底色、进度) |
| `features.js` / `features.css` | 人物检索与关系图、时间线、全文搜索、划线批注书签金句卡、我的书房、分享 |
| `theme.css` / `cards.css` | 围涂自己的外观:夜涂、卷宗、档案袋三种底色;手机、文档、聊天等卡片 |
| `scene.js` / `wt.js` | 海涂画面、风声、章首案卷号、书封、目录“核”字、围垦进度 |
| `ch01.html` … `ch20.html` | 旧版每章单页的地址,打开后跳到 `index.html#chNN`,老链接不失效 |
| `.nojekyll` | 告诉 GitHub Pages 不要用 Jekyll 处理 |

## 部署到 GitHub Pages

1. 新建仓库,把本目录里的**全部文件**(含 `.nojekyll`)放在仓库根目录。
2. 仓库 Settings → Pages → Source 选 `Deploy from a branch`,Branch 选 `main`,目录选 `/ (root)`。
3. 等一两分钟,打开 `https://<用户名>.github.io/<仓库名>/`。

本地预览:在本目录运行 `python3 -m http.server 8000`,打开 `http://localhost:8000/`。

## 功能

- 阅读:三种底色(夜涂、卷宗、档案袋)、字号、风声、续读位置、每章前情提要
- 人物:检索、人物卡、出场章节、关系图;正文里的人名可以点开
- 时间线:按事件跳到对应章节或段落
- 全文搜索
- 划线、批注、书签、金句卡(可保存成图片)
- 我的书房:读完几章、阅读时长、连读天数、划线与书签清单
- 三部曲跳转、分享某一章或某一段的链接

划线、批注、书签、阅读进度都存在读者自己的浏览器里,换设备或清除网站数据后不会跟过去。

没有评论和读后感:这些需要后端,纯静态页面做不了,所以这一版没有。

## 需要联网的部分

关系图(从 jsDelivr 加载 vis-network)和字体(Google Fonts)。加载不了时,关系图退回成人名列表,字体退回系统字体。

## 分享链接

分享时用的是当前页面自己的地址,部署在哪里,分享出去的就是哪里。
